## 説明
偏角ソートのcmp関数です。

以下、すべて反時計回りで考える。\\
偏角の差が180度未満の場合、外積 $x_1y_2 - y_1x_2$ の符号によって順序を判定できる。(外積が正でAはBより偏角が小さい)

360度の場合、まず半平面に分ける必要がある。この比較関数は第1象限 -> 第2象限 -> 第3象限 -> 第4象限 となっている。

## 計算量
$O(1)$
